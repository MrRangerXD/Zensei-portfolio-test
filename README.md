# Zensei Prestige Portfolio

A premium, Emerald-themed portfolio for the founder of Zensei Network.
Built with Next.js 15, Tailwind v4, and Framer Motion.

## Setup
1. `npm install`
2. `npm run dev`

## Design System
- Theme: Emerald Prestige
- Palette: #000000 (Primary), #10B981 (Accent)
- Spacing: 80px/120px Section Gutters
